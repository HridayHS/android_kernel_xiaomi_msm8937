# android_kernel_xiaomi_msm8937

Kernel source for Redmi 3/3S/3X (land) and Redmi 4/4X (santoni).

Base: LineageOS 15.1 (Android 8.1), Qualcomm MSM8937 platform.

This is the kernel tree ROM builders use for these devices. It is maintained as-is for the custom ROM community — no vendor support remains for these phones, so this tree keeps custom ROMs building for them.
